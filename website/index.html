    Under the hood

    How it works

    A Spring AOP aspect intercepts annotated methods and routes them through a framework-agnostic engine.

    1

    Intercept

    The DevLensAspect wraps any method carrying a DevLens annotation via an @Around advice.

    2

    Build context

    An InterceptionContext captures the method, arguments and annotations, decoupled from Spring.

    3

    Process

    The engine runs pre-steps, executes your method, then runs post-steps — each in its own try/catch.

    4

    Pass through

    Your return value or exception is returned to the caller exactly as-is.

    devlens-annotationsPure @interface definitions. Zero dependencies.
    ↓
    devlens-coreFramework-agnostic engine. Depends on SLF4J only.
    ↓
    devlens-spring-boot-starterAuto-configuration + AOP glue for Spring Boot 3.x.
    Full control

    Configure per environment

    Every feature has a toggle. Turn off input logging in production, tighten thresholds, or add masked fields — all through properties. Sensitive fields like password and token are masked automatically.

    passwordtokenauthorization accessTokensecretcardNumbercvv 
    devlens:
  enabled: true
  max-output-length: 5000

  execution-time:
    enabled: true
    threshold: 500

  log-input:
    enabled: false   # off in prod

  masking:
    fields:
      - apiKey
      - socialSecurityNumber
    # Global kill switch
devlens.enabled=true
devlens.max-output-length=5000

# @ExecutionTime / @SlowMethod
devlens.execution-time.enabled=true
devlens.execution-time.threshold=500

# Turn off input logging in prod
devlens.log-input.enabled=false

# Extra fields to always mask (comma-separated)
devlens.masking.fields=apiKey,socialSecurityNumber
    Three steps

    Get started

    From dependency to your first trace in under a minute.

    1

    Add the dependency

    pom.xml
    <dependency>
  <groupId>com.devlens</groupId>
  <artifactId>devlens-spring-boot-starter</artifactId>
  <version>1.0.0-SNAPSHOT</version>
</dependency>
    2

    Annotate a method

    DemoController.java
    @GetMapping("/hello")
@ExecutionTime
@LogInput
@LogOutput
public String hello(@RequestParam String name) {
    return "Hello, " + name;
}
    3

    Run & watch the logs

    console
    [DevLens] LogInput ... args=[name=World]
[DevLens] ExecutionTime ... executionTime=3ms
[DevLens] LogOutput ... result=Hello, World
    Grab the build

    Download the JAR

    Prefer to drop the artifact straight into your project? Download the Spring Boot starter JAR, or build all modules from source.
